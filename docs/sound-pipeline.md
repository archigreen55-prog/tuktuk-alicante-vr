# Звуки Crazy Tuk: скачування, збірка, примірочна

Версія 0.18.0. Усе, що стосується звуків, живе в одному файлі **`assets/audio-src/sounds.json`**: джерела (Freesound, Kenney: назва, автор, ліцензія), затверджені
звуки (слот ← джерело) і кандидати для примірочної.

## Команди

```
node tools/fetch-sounds.mjs                 # скачати все: HQ-прев'ю Freesound (cdn.freesound.org) і zip-пакети Kenney (kenney.nl) в assets/audio-src/dl/ (не в git)
node tools/fetch-sounds.mjs --list kenney-impact   # які файли в пакеті (щоб уточнити шаблони в sounds.json)
node tools/build-sounds.mjs                 # зібрати затверджені (assets/audio/ + manifest.json + CREDITS.md) і кандидатів (assets/audio-cand/)
node tools/build-sounds.mjs --approved      # лише затверджені;  --candidates: лише кандидати
```

Потрібен доступ до **freesound.org, cdn.freesound.org, kenney.nl** (налаштування мережі середовища) і `ffmpeg`, `unzip`, `curl`.

## Як працює збірка

- **Затверджені** (`approved`): `слот ← джерело`; для Kenney джерело задається шаблоном `ключ:назва*` (наприклад `kenney-impact:impactMetal_heavy_*`, `pick` = скільки файлів
  узяти за алфавітом). Кожен ефект: моно, вирівняний за гучністю (−18 LUFS), без тиші на початку, не довший за 3 с (`max`, клаксон 1.4 с із затуханням). `slots.<слот>.gain`
  це рівень слота в грі (`manifest.gain`): клаксон і туристи 1.0, удари 0.8–1.0, дзвіночки воріт 0.45–0.55, двигун тихо (0.10–0.26). Подяки йдуть у `assets/audio/CREDITS.md`;
  роботи **CC BY** ще й у `manifest.attribution`: гра показує їх рядком «Звуки: «назва», автор, ліцензія (посилання)» внизу сторінки й у меню ≡.
- **Кандидати:** цикли (двигун, вереск, нітро) знаходять **рівну ділянку** запису (`tools/lib/audio-analysis.mjs`: найменша зміна гучності й спектрального центроїда) і
  робляться безшовним циклом (хвіст 0.4 с зводиться з початком); сміх і «Wooo» вирізаються за гучністю (найгучніші фрагменти `bursts: N`, довжина `min`–`max`). Це **автоматика за
  гучністю, а не «найвеселіше»: смак обираєш ти на слух**.
- Слоти розбивання: `smash.c` (конус), `smash.b` (смітник), `smash.t` (столик), `smash.u` (парасоля); якщо файлу нема, грає загальний `smash`.

## «Звуки» (примірочна, тільки на пристрої з ключем редактора)

Меню ≡ → **Звуки** (на ПК клавіша **L**). Для кожного слота список кандидатів: ▶, назва, автор, ліцензія, нотатка (де вирізано), посилання, **Вибрати**.

- Повзунок **Швидкість 0–150 км/год** змінює тон і гучність циклу двигуна **тією самою формулою, що в грі** (`engineParams` у `src/audio/arcadeSound.js`):
  0 км/год: тон ×0.7, гучність 0.10; 150: тон ×1.9, 0.26. Повзунок **Ковзання** відкриває вереск так, як у грі (`squealParams`).
- **Мікс з двигуном:** коли грає вереск або нітро, під ним грає вибраний (або перший) двигун на швидкості повзунка: чути, чи звуки не заглушають одне одного.
- Цикл: один вибір на слот; ефекти: можна кілька (у грі випадковий із вибраних).
- **📋 Копіювати вибір:** текст на кшталт `engine: fs177754 (Tuk tuk engine, kyles)` / `horn: fs423990, fs27881` / `не вибрано: …`; вставляєш його мені в чат.
- Вибір зберігається на пристрої (`tuktuk.soundlab.v1`). Примірочна грає через власний AudioContext і на час відкриття вимикає музику гри.
