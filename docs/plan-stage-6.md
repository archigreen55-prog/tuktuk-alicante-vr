## 0. Затверджені зміни (2026-09-28)

Мають пріоритет над рештою плану.

1. **Зону не розширюємо.** Круїзний термінал не потрібен. Туристів забираємо біля головного входу **готелю Meliá Alicante**. Там же старт і фініш туру.
2. **Маршрут — справжній маршрут гіда**, у такому порядку:
   Meliá → Casa Carbonell → Explanada de España → Parque de Canalejas (фікуси) → Casa de las Brujas → будівля університету (Calle San Fernando, 40) → Rambla de Méndez Núñez → Ayuntamiento → Basílica de Santa María → Playa del Postiguet (вид на замок) → ~~Plaza de Toros~~ → Mercado Central → Plaza de los Luceros → Calle San Francisco («вулиця грибів») → Meliá.
   - Тук-тук не заїжджає в пішохідні зони. Маршрут прокладається лише проїзними вулицями й з урахуванням односторонніх.
   - **Справжні зупинки з фото — 5:** Explanada і Casa Carbonell, Ayuntamiento, Basílica de Santa María, Postiguet (вид на замок), Mercado Central. Решта точок — **«факти на ходу»**: текст на панелі, коли проїжджаєш поруч.
   - Два тури:
     - **«короткий»** — лише 5 зупинок;
     - **«повний»** — весь маршрут із фактами на ходу.
3. **Пасажирів до 4** (дві пари). У тук-тук додається друга лавка.
4. **Лайнер** — лише декорація в порту, яку видно з Explanada й Postiguet. До терміналу не їдемо. Робиться в 6b.
5. **Двигун електричний:** звук електромотора, а не бензинового.
6. **«Ой» і оплески** синтезуються. Закладаю можливість пізніше замінити їх записами з `assets/sfx/`.
7. **Дві викладки:**
   - **6a** — тур без звуку й реакцій;
   - **6b** — звук, реакції, лайнер.

**Відкладено на v2** — точки поза поточною зоною:
- **Plaza de Toros** — стоїть на північ від Plaza de España, яка сама на самій межі зони;
- MARQ;
- під'їзд до замку;
- Castillo de San Fernando;
- стадіон;
- ADDA.

## 1. Як це виглядатиме

1. **Стартовий екран.** «Режим: тур / вільна їзда» і «Тур: короткий / повний». Поруч — найкращий результат. Вибір запам'ятовується.
2. **Старт біля Meliá.**
   - Тук-тук стоїть на Passeig del Port, за ~45 м до входу в готель, носом до нього.
   - Біля входу на тротуарі чекає група з 2–4 туристів: одна або дві пари.
   - На дорозі біля них — жовта світлова зона й стовп світла.
3. **Посадка.**
   - Під'їжджаєш повільно й зупиняєшся в зоні. Туристи підходять і сідають: перша пара — на першу лавку, друга — на другу.
   - На панелі — вступ із `tour.json`, стартує таймер.
4. **Їзда.**
   - Стрілка-компас на панелі показує на наступну точку маршруту. Мінікарта ліворуч від панелі показує лінію маршруту проїзними вулицями.
   - Наступна зупинка світиться зоною й стовпом світла.
   - Проїжджаєш поруч із точкою «на ходу» — на панелі 8–10 с висить її назва й текст.
5. **Зупинка.** В'їхав у зону й зупинився — таймер на паузі, 6 с «фото». На панелі картка: назва й факт. Далі «Можна рушати · Далі: …». Картка лишається, доки не рушиш.
6. **Оцінка плавності** працює весь тур. Різке гальмування, швидкий поворот чи удар — коротке повідомлення на панелі й мінус до настрою групи.
7. **Фініш біля Meliá.** Туристи виходять і йдуть до готелю. На панелі підсумок:
   - зірки, чайові, час проти цільового;
   - події й відгук;
   - скільки фактів на ходу зібрано;
   - найкращий результат.

   Y або T — новий тур.
8. **Вільна їзда** — як зараз, старт на Rambla.

**6a — усе вище, крім:** звуку (двигун, оплески, «ой», затвор), живих реакцій туристів (хитання, погляди, фото зі спалахами, оплески) і лайнера. У 6a туристи підходять, сідають, сидять нерухомо й виходять.

Пошук місця:
- **поля:** `name`, `name:es`, `name:ca`, `name:en`, `official_name`, `alt_name`, а також `wikipedia` і `wikimedia_commons` — без них Meliá й Casa de las Brujas не знаходяться;
- **збіг:** підрядок без урахування регістру й наголосів;
- **пріоритет:** будівля > площа або парк > вулиця > точка;
- замість назви можна дати точний id (`"osm": "way/…"`);
- `"road"` вибирає вулицю для прив'язки, `"at": [lat, lon]` — точне місце, якщо автоматика поставила не туди.

| Тур | Точки | Довжина | Їзда (оцінка) |
|---|---|---|---|

### 2.3 `data/tour.json` — редагуєш сам
```json
{
  "tours": [
    { "id": "short", "title": "Короткий тур", "start": "melia",
      "route": [ { "stop": "explanada" }, { "stop": "townHall" }, { "stop": "santaMaria" },
                 { "stop": "postiguet" }, { "stop": "mercado" } ] },
    { "id": "full", "title": "Повний тур", "start": "melia",
      "route": [ { "stop": "explanada" }, { "pass": "canalejas" }, { "pass": "brujas" }, { "pass": "university" },
                 { "pass": "rambla" }, { "stop": "townHall" }, { "stop": "santaMaria" }, { "stop": "postiguet" },
                 { "stop": "mercado" }, { "pass": "luceros" }, { "pass": "sanFrancisco" } ] }
  ],
  "places": {
    "melia":     { "title": "Готель Meliá", "osm": "Hotel Meliá Alicante", "road": "Passeig del Port", "fact": ["ЗАГЛУШКА: привітання."] },
    "explanada": { "title": "Explanada і Casa Carbonell", "osm": "Casa Carbonell", "road": "Passeig dels Màrtirs de la Llibertat", "fact": ["ЗАГЛУШКА"] }
  },
  "reviews": { "great": ["…"], "brakes": ["…"], "turns": ["…"], "hits": ["…"], "late": ["…"] }
}
```
- Тур — це старт, список `route` і повернення на старт. У `route` будь-яке місце може бути `stop` (зупинка з фото) або `pass` (факт на ходу).
- **Без збірки** (досить зберегти файл і оновити сторінку): тексти, порядок і склад маршруту, зупинка чи «на ходу», тури, відгуки.
  - Маршрут рахується в грі.
  - Файл вантажиться в обхід кешу.
  - Зламаний JSON — помилка на стартовому екрані, вільна їзда працює далі.
- **Потрібно `node tools/build-city.mjs`:** нове місце або змінені `osm`, `road`, `at`. Скрипт друкує, що знайшов, і довжини відрізків.

### 2.4 Що пише `build-city` у `city.json`
- **`tour.places.<id>`** — для кожного місця:
  - точка на дорозі, напрям дороги й ширина;
  - точка, куди дивитись;
  - геометрія для спрацювання «на ходу»;
  - OSM id.

  Точки ближче 30 м до межі зони не беруться.
- **`tour.graph`** — граф проїзних вулиць для маршрутів:
  - включено primary…residential, living_street і service без `access=private`;
  - без пішохідних, сходів і автобусних смуг;
  - з односторонністю.

У грі маршрут рахує A* з прив'язкою до найближчого **ребра**, а не вузла: інакше точку на двосмуговій вулиці чіпляло б до зустрічної смуги, і маршрут робив би зайве коло.

## 3. Логіка туру

| Стан | Що відбувається | Далі |
|---|---|---|
| Очікування | Група біля входу Meliá, зона посадки, стовп світла | Тук-тук у зоні, швидкість < 3 км/год протягом 0.6 с |
| Посадка (2.5 с) | Туристи йдуть до тук-тука й сідають. Автоутримання гальма | Рушив раніше — посадка скасовується |
| Їзда | Ціль — наступна точка маршруту. Факт на ходу спрацьовує ближче 25 м від місця або 30 м від його точки на дорозі | Зупинився в зоні зупинки: < 1 км/год протягом 0.5 с |
| Фото (6 с) | Таймер на паузі, автоутримання, картка факту | Рушив раніше — «Ще фотографуємо!», −5 настрою, зупинка не зарахована |
| Після фото | «Можна рушати · Далі: …», ціль уже наступна | Рушив швидше 3 км/год |
| Фініш | Зупинка в зоні Meliá — туристи виходять (3 с) | Підсумок |

- **Пропущений факт на ходу.** Якщо ти дістався до пізнішої точки, а раніший факт не спрацював, він позначається пропущеним без штрафу. У підсумку: «Факти на ходу: 5/6».
- **Автоутримання.** Поки йде посадка, фото чи висадка, утримання гальма не вмикає задній хід. Зараз задній хід вмикається через 0.4–0.5 с, і тук-тук виповз би із зони.
- **Маршрут на мінікарті** рахується на початку кожного відрізка. З'їхав із нього далі ніж на 60 м довше 3 с — маршрут перераховується від поточного місця, не частіше разу на 5 с.
- **Перезапуск.** Y (VR) або T (клавіатура) двічі за 2 с — посеред туру чи з вільної їзди. Після підсумку досить одного натиску.

## 4. Оцінка плавності, чайові, зірки

### 4.1 Події
Сигнали щокадру з `physics.js`:
- **гальмування** `a_br` — лише коли водій гальмує й не їде назад, згладження 0.15 с;
- **бічне прискорення** `a_lat` = |v·ω|, згладження 0.2 с;
- **удар** — `lastImpact`, м/с у стіну.

Одна подія одного типу — не частіше ніж раз на 1.5 с. Настрій групи починається зі 100.

| Подія | Умова | Настрій |
|---|---|---|
| Різке гальмування | `a_br` ≥ 3.5 м/с² довше 0.3 с (тригер гальма > ~60 %) | −6 |
| Екстрене гальмування | `a_br` ≥ 5.0 м/с² довше 0.2 с | −12 (замість −6) |
| Швидкий поворот | `a_lat` ≥ 3.0 м/с² довше 0.4 с | −5 |
| Небезпечний поворот / занос | `a_lat` ≥ 4.5 м/с² довше 0.3 с, або ручник на > 10 км/год | −10 |
| Дотик до стіни | 0.5–2 м/с | −4 |
| Удар | 2–4 м/с | −12 |
| Сильний удар | > 4 м/с | −25 |
| Шкрябання стіни | контакт > 1 с на > 5 км/год | −2/с |
| Швидко біля людей | > 15 км/год ближче 8 м від групи, що чекає | −5 |
| «На дорогу» (R, A+B, обидва grip) | під час туру | −10 |
| Поїхав під час фото | — | −5 |
| М'яка зупинка | за 5 с до зупинки гальмування ≤ 2.5 м/с² | +3 |
| Спокійна їзда | 15 с без подій | +1 (до 100) |

Орієнтир для повороту на 90° радіусом ~8 м:
- 15 км/год — 2.2 м/с², нормально;
- 20 км/год — 3.9 м/с², «швидкий»;
- 25 км/год — 6 м/с², «небезпечний».

**Клавіатура.** Гальмо з S тепер наростає: 0.35 → 1.0 за 0.6 с. Натиск до ~0.5 с — плавне гальмування; утримання довше — різке. Задній хід утриманням S працює як раніше.

### 4.2 Час, чайові, зірки
- **Цільовий час** рахується за маршрутом:
  - швидкість за типом вулиці: primary/secondary — 8 м/с, service — 7, tertiary — 6.5, residential — 5.5, living_street — 4;
  - плюс 3 с на поворот > 50°;
  - таймер стоїть, поки стоїш у зоні зупинки;
  - свій час можна задати в `tour.json` полем `targetMin`.
- **Чайові з кожного туриста** = 10 € × (настрій/100)^1.5 + бонус: вчасно +4 €, до +25 % понад цільовий +2 €, пізніше 0. Сума округлюється до 0.50 €.
- **Зірки:** настрій ≥ 90 → 5★, ≥ 75 → 4★, ≥ 60 → 3★, ≥ 40 → 2★, менше → 1★. Запізнення понад 25 % знімає ще одну зірку, мінімум лишається 1★.
- **Відгук** — фраза з `reviews` за найбільшою групою штрафів.
- **Найкращий результат** кожного туру зберігається в localStorage.
- Усі пороги — в одній таблиці-константі. Калібрування — автопілотом у Node: «обережний водій» має отримати 5★, «різкий» — не більше 2★.

## 5. Тук-тук на 4 пасажирів і туристи

- **Друга лавка.**
  - Кузов подовжується на ~0.7 м назад. Друга лавка стоїть за першою, обидві лицем уперед, тож, озирнувшись, бачиш обидві пари.
  - Дах, підлога, борти й задня стінка подовжуються, задні колеса зсуваються назад.
  - У колізії додається третє коло ззаду. Хвіст у тісних поворотах замітає трохи ширше — як у справжнього довшого тук-тука.
- **Туристи.**
  - 2–4 фігури: одна або дві пари. Вигляд випадковий: шкіра, яскравий одяг, панама чи кепка, окуляри.
  - ~300 трикутників на фігуру.
  - Один `SkinnedMesh`, ~11 кісток на фігуру — **1 draw call**.
  - Поки чекають — стоять на тротуарі, після посадки сидять у тук-туку. Кістки просто переходять від світу до тук-тука.
- **6a:** підходять кроком, сідають, сидять нерухомо, на фініші виходять.
- **6b:** хитання від перевантажень, погляд на пам'ятки, фото зі спалахами, оплески, «ой».

## 6. Звук (6b)

- **Електромотор.**
  - Свист мотора з тоном, пропорційним швидкості: ~60 → ~440 Гц основний плюс 2–3 обертони.
  - На газу трохи гучніше й вище (+5 %).
  - Шум шин і трансмісії наростає зі швидкістю.
  - Рекуперація при гальмуванні — тон трохи інший.
  - Тихе клацання контактора на старті.
  - Синтез — прості осцилятори й шум (`AudioWorklet` не потрібен).
- **Оплески, «ой», затвор камери, дзвіночки** — синтез, як у початковому плані.
  - Якщо в `assets/sfx/` лежить файл із відповідною назвою (`clap`, `oy-1`…`oy-4`, `shutter`, `chime`; `.ogg` або `.mp3`), гра грає його замість синтезу.
  - Перелік імен буде в README.
- Спільний `AudioContext`, звуки туристів ззаду (HRTF), повзунок гучності й вимикач двигуна.

## 7. UI на панелі

- **Панель:**
  - 0.50 × 0.25 м замість 0.42 × 0.21;
  - canvas 768×384 замість 512×256 — у 1.5 раза чіткіший текст;
  - перемальовується лише при змінах, не частіше 5 разів на секунду.

  Режими:
  - **їзда** — швидкість, «Зупинка i/N» або «Далі: …», відстань, таймер, настрій, чайові ≈, повідомлення, текст факту на ходу;
  - **картка** — на зупинці;
  - **підсумок**.
- **Стрілка-компас.** Меш-стрілка в площині панелі, як у навігаторі: вгору — ціль попереду, крутиться щокадру. Це замість 3D-стрілки над панеллю: горизонтальну стрілку під кутом ~9° погано видно.
- **Мінікарта.** Коло ⌀ 17 см ліворуч від панелі, курсом угору.
  - Карта міста малюється в текстуру один раз, 1.5 м/px.
  - Маршрут — друга текстура, половинна роздільність. Оновлюється лише тоді, коли змінюється маршрут.
  - Шейдер щокадру зсуває й повертає UV, тож обертання плавне.
  - Разом **1 draw call**.
- **Зона й стовп світла** — 2 draw calls, прозорі.
- **ПК.** Статус туру, картку й підсумок дублює HTML-блок. Мінікарта — невеликий canvas у куті (M ховає).
- **Кнопки:**
  - Y коротко / T — тур: новий після підсумку, двічі за 2 с — заново;
  - M — мінікарта на ПК.

  Y утримати 1 с — перецентрування, як і було.

## 10. Ризики

| Ризик | Заходи |
|---|---|
| Пороги оцінки несправедливі (клавіатура проти тригерів) | Наростання гальма S, калібрування автопілотом, твій тест |
| Утримання гальма на зупинці вмикає задній хід | Автоутримання на посадці, фото, висадці |
| Прив'язка точки не до того боку вулиці або не до тієї вулиці | Прив'язка до ребра, `road` / `at` у `tour.json`, друк довжин відрізків |
| Довгий кузов частіше чіпляє стіни в старому місті | Третє коло колізії лише ззаду. Якщо заважає — скоротити подовження |
| Повний тур довгий для VR (~25 хв) | Короткий тур — типовий, перезапуск будь-коли |
| Текст факту не читається у VR | 768×384, шрифт ≥ 24 px, скріни в емуляторі, остаточно — шолом |
| Адреса університету в OSM інша (Ramón y Cajal, 4) | Якщо мав на увазі інший будинок — `osm` або `at` у `tour.json` |
