# Рівні Crazy Tuk: формат файлу і як додати рівень

Версія формату `schema: 1` (з гри 0.16.0). Один рівень = один файл `data/levels/<id>.json`; список рівнів і їхній порядок = `data/levels/index.json`.
Той самий файл читають гра, `tools/sim-arcade.mjs` (автопілоти) і редактор.

## Файл рівня

```json
{
  "schema": 1,
  "id": "short",
  "title": {"uk":"Короткий тур","en":"Short tour","es":"Tour corto"},
  "type": "standard",
  "start": {"place":"melia"},
  "time": {"mode":"auto","par":309},
  "items": [
    {"k":"via","p":[585,123]},
    {"k":"gate","place":"explanada"},
    {"k":"gate","p":[427,67],"d":[0.9,-0.4],"title":"Ayuntamiento","fact":"одна фраза до 70 символів"},
    {"k":"gate","place":"melia","finish":true}
  ],
  "rules": {},
  "extras": {}
}
```

| Поле | Значення |
|---|---|
| `id` | латиницею, цифри, `-`, `_`, до 40 символів; за ним зберігаються рекорди гравця (`tuktuk.arcade.best.<id>`) |
| `title` | назва трьома мовами `uk`, `en`, `es` (до 40 символів кожна); `uk` обов'язкова; порожні `en`/`es` перекладаю я, коли додаю рівень у гру |
| `type` | `standard` (є), `stay-on-road` («Не з'їжджай з дороги», з 0.17.0, правила нижче), `stunt` (польоти, не кодуємо) |
| `start` | `{"place": "<id місця з tour.json>"}` або точка `{"x": …, "z": …, "heading": …}` (радіани; туктук дивиться вздовж `-sin, -cos`) |
| `time` | `mode: "auto"`: час рахується (par від моєї симуляції або, якщо `par: null`, від довжини шляху × 0.06 с/м); `mode: "manual"`: `par` у секундах (20–3600) задаєш ти |
| `items` | порядок проходження. **Останні ворота = фініш** (`"finish": true`), інші ворота його не мають |
| `rules`, `extras` | для типів рівнів (див. нижче); невідомі поля старі версії ігнорують |

### Елементи `items`

- `{"k":"gate","place":"<id>"}`: ворота на готовому місці (координати, напрямок дороги, назва з `tour.json`, факт з `arcade-facts.json`);
  необов'язкове `fact` перекриває факт місця.
- `{"k":"gate","p":[x,z], "d":[dx,dz], "title":"…", "fact":"…", "w":8}`: вільні ворота; `d` напрямок дороги (редактор ставить сам, без нього напрям береться з
  найближчої дороги графа); `title` (до 40) і `fact` (до 70 символів) показуються на картці, `w` ширина.
- `{"k":"via","p":[x,z], "r":16}`: проміжна точка «через»: без оцінки й чайових, зараховується в радіусі `r` (за замовчуванням 16 м), стрілка веде
  через неї; належить до **наступних** воріт; за 70 м до воріт решта «через» цього відрізка скидається.

### Правила (перевіряє `validateLevel`)

- ворота від **3 до 12 разом із фінішем**;
- фініш останній; «через» не стоїть після фінішу;
- факт воріт до 70 символів; назва до 40;
- `time.manual`: 20–3600 с.

## Тип `stay-on-road` («Не з'їжджай з дороги»)

Вихід за коридор вулиці карається. Коридор: вісь тук-тука не далі від осі вулиці, ніж **половина ширини асфальту вулиці + `margin`** (ширина за класом
вулиці: головні 11 м, сервісні 5, tertiary 8, житлові 6.5, пішохідні/living street 5; `ROAD_HALF` у `src/game/route.js`). Правила в `rules` (усі необов'язкові):

| Ключ | За замовчуванням | Значення |
|---|---|---|
| `margin` | 1.0 | м за краєм асфальту, які ще вважаються дорогою (0–4) |
| `grace` | 0.5 | с поза дорогою до початку штрафу (0–5) |
| `timePenalty` | 2 | додатково с годинника за кожну секунду поза дорогою (0–10): годинник іде втричі швидше |
| `burn` | 0.25 | частка чайових «на кону», що згоряє за секунду поза дорогою (0–1) |

Поза дорогою: червоний край екрана й напис «З ДОРОГИ!», комбо скидається, у підсумку рядок «З дороги: N разів · X с · згоріло Y €». Граф доріг для цього
правила без 45 непрохідних відрізків (`data/drive-graph.json`). У редакторі зелена смуга на карті показує коридор уздовж маршруту.

Приклад: `"type": "stay-on-road", "rules": {"margin": 1.5}`.

## Як додати рівень вручну (поки немає кнопки «Поділитися»)

1. Поклади файл у `data/levels/<id>.json`.
2. Додай рядок у `data/levels/index.json` (`{"id": "...", "file": "....json", "type": "standard", "gates": N, "title": {...}}`; `"builtin": true` лише для трьох вбудованих).
3. `node tools/sim-arcade.mjs data/levels/<id>.json` перевіряє його автопілотами й показує час (par).
4. `node tools/make-levels.mjs` перегенерує три вбудовані рівні з `tour.json`, `arcade-via.json`, `arcade-par.json` (рівні, додані вручну, не змінює).
5. `node tools/bump-version.mjs <ver>`, коміт, push у `main`.

## Три вбудовані рівні

`short`, `castle`, `full` генеруються `tools/make-levels.mjs` з `data/tour.json` (маршрут), `data/arcade-via.json` (проміжні точки; `tools/arcade-vias.mjs`) і
`data/arcade-par.json` (час; `tools/sim-arcade.mjs <id> --par --write`). Після зміни будь-якого з цих трьох файлів запусти `make-levels`. Рекорди гравців не втрачаються:
ключ `arcade.best.<id>` той самий, що був.
