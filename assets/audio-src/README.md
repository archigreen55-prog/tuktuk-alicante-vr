# Як додати свій звук

1. **Формат:** WAV, MP3, OGG або FLAC; будь-яка частота; моно чи стерео (гра сама зробить моно й вирівняє гучність). Короткий ефект: до 3 с.
   Звук, що грає безперервно (двигун, вереск, нітро): 4–10 с рівного звуку, без початку й кінця, я зроблю з нього безшовний цикл.
2. **Куди покласти:** у цю папку, `assets/audio-src/`, через GitHub: відкрий https://github.com/archigreen55-prog/tuktuk-alicante-vr/upload/main/assets/audio-src ,
   перетягни файл, натисни «Commit changes». Назва файлу будь-яка, латиницею, без пробілів (наприклад `horn-my.wav`).
3. **Що написати мені в чат** (по одному рядку на файл):
   - назва файлу;
   - для чого він: клаксон, удар, ворота, розбивання, двигун, вереск, нітро, сміх, крик, «Wooo» або інше (опиши словами);
   - звідки він: «записав сам» або посилання на сторінку й ліцензію (CC0, CC BY: для CC BY ще автор і назва для подяки);
   - побажання, якщо є: «тихіше», «лише перші 2 секунди» тощо.

   Приклад: `horn-my.wav — клаксон, записав сам, трохи тихіше`.

Далі все роблю я: підключаю файл у `sounds.json`, збираю (`node tools/build-sounds.mjs`), перевіряю й випускаю нову версію.
Технічні подробиці: [docs/sound-pipeline.md](../../docs/sound-pipeline.md).
